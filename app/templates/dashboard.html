Dashboard d’analyse de données

Analyse, visualisation et cartographie dynamique de données Excel.

Comment utiliser le dashboard ?

1. Importez votre fichier Excel.

2. Sélectionnez la feuille à analyser.

3. Cliquez sur « Lancer l’analyse automatique » pour générer les résultats.

L’application détectera automatiquement les colonnes, les statistiques pertinentes et les graphiques adaptés.
